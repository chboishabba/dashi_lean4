# Millennium Submission Max-Cut Design

## Intent

Move from broad internal Millennium theorem surfaces to a submission-grade acceptance discipline in which completion means an exact independent target theorem, kernel receipt, expected axiom set, minimal proof cone, and referee-readable mathematical proof.

## Binding decisions

- PR #45 remains the external-target acceptance spine.
- Existing same-object / physical-object welds are searched and composed before any new mathematical interface is introduced.
- The external adapter layer may expose missing representation lemmas but may not invent a new Millennium hypothesis.
- Navier–Stokes C is the first external-acceptance target because the released comparator theorem already supplies the mathematical breakdown witness; only representation transport should remain.
- One Fefferman alternative is sufficient, so C is primary and D is audit redundancy once C is exact.
- RH, BSD, and P-vs-NP remain RED-MATH until their exact mathematical producers exist.
- Hodge and Yang--Mills cannot be promoted against the pinned upstream revision because those statement interfaces are explicitly incomplete.

## Success criterion

The first milestone is an unconditional theorem of the exact pinned `MillenniumNavierStokes.FeffermanC` proposition with a clean `#print axioms` audit.  If that theorem cannot yet be produced, the tranche must leave a strictly smaller theorem-bearing representation frontier than the former opaque statement equivalence.
