Отже, кожна категорія К складається з елементів двох класів — Ob K обʼєктів (множин, тополог. просторів, груп) та Mor K морфізмів (від­ображень множин одна в одну, гомоморфізмів груп, кілець, алгебр, неперерв. від­ображень тополог. просторів та ін.). Кожний морфізм M категорії К має одно­значно ви­значені початок — обʼєкт A та кінець — обʼєкт B. Усі морфізми зі спіл. початком A та кінцем B утворюють під­множину HK(A, B) класу Mor K. Морфізм M є Mor K належить одній і тільки одній множині HK(A, B). Пів­група з одиницею є категорією з одним обʼєктом, і, навпаки, кожна категорія з одним обʼєктом є пів­групою з одиницею. У наведених прикладах усі категорії конкретні, тобто ізоморфно вкладаються в категорію множин. Але не всі категорії є конкретними. Запас прикладів категорій можна значно роз­ширити за допомогою різноманіт. кон­струкцій, зокрема категорії функторів або категорії діа­грам. У 1950-х рр. теоретико-категор. аналіз основ теорії гомологій зумовив появу т. зв. абелевих категорій, у рамках яких стало можливим зробити осн. побудови гомолог. алгебри. У на­ступ. десятиліт­ті значно зріс інтерес до неабелевих категорій, які сприяли роз­вʼязан­ню нових задач логіки, заг. алгебри, топології та алгебраїч. геометрії. Інтенсив. роз­виток універсал. алгебри й аксіоматичні побудови теорії гомотопій заклали основи категор. ви­вче­н­ня многовидів універсал. алгебр, теорії ізоморфізмів прямих роз­кладів, теорії спряжених функторів, теорії дво­їстості функторів. Остан. часом виявлено сут­тєві взаємозвʼязки між цими дослідже­н­нями. <header>            
            <h1>
                Категорій теорія            </h1>


</header>

<div class="article-body"><span id="section-def" style="display:block;height:0;overflow:hidden;"></span><p><b>КАТЕГО́РІЙ ТЕО́РІЯ</b>&nbsp;— роз­діл <span class="M"><I>математики</I></span>, в основі якого лежить поня­т­тя категорії, яке виділяє низку алгебраїчних властивостей сукупностей морфізмів однотипних математичних обʼєктів за умови, що ці сукупності містять тотожні пере­творе­н­ня та є за­мкненими від­носно послідовного викона­н­ня (суперпозиції або множе­н­ня) від­ображень. Отже, кожна категорія <i>К</i> складається з елементів двох класів&nbsp;— <i>Ob K</i> обʼєктів (множин, тополог. просторів, груп) та <i>Mor K</i> морфізмів (від­ображень множин одна в одну, гомоморфізмів груп, кілець, алгебр, неперерв. від­ображень тополог. просторів та ін.). Кожний морфізм <i>M</i> категорії <i>К</i> має одно­значно ви­значені початок&nbsp;— обʼєкт <i>A</i> та кінець&nbsp;— обʼєкт <i>B</i>. Усі морфізми зі спіл. початком <i>A</i> та кінцем <i>B</i> утворюють під­множину <i>H<sub><small>K</small></sub>(A, B)</i> класу <i>Mor K</i>. Морфізм <i>M</i> <i>є</i> <i>Mor K</i> належить одній і тільки одній множині <i>H<sub><small>K</small></sub>(A, B)</i>. Множина <i>H<sub><small>K</small></sub>(A, B)</i> обовʼязково містить тотож. морфізм і в класі <i>Mor K</i> за­дано частковий закон множе­н­ня: добуток <i>M<sub><small>1</small></sub></i> <i>M<sub><small>2</small></sub></i> морфізмів <i>M<sub><small>1 </small></sub></i><i>є</i> <i>H<sub><small>K</small></sub>(A, B)</i> і <i>M<sub><small>2</small></sub></i> <i>є</i> <i>H<sub><small>K</small></sub>(C, D)</i> ви­значений лише тоді, коли B = C і належить множині <i>H<sub><small>K</small></sub>(A, D)</i>. При цьому для довіл. морфізмів з <i>Mor K</i> виконується закон асоціативності. Поня­т­тя «категорія» введено 1945. Походже­н­ня та роз­виток К. т. повʼязаний з алгебраїч. топологією. Унаслідок дослідж. виявлено обʼ­єд­нуючу й уніфікуючу ролі категорії і повʼязаного з нею поня­т­тя «функтор» для багатьох роз­ділів математики. Приклади категорій: <i>Ens</i> (клас <i>Ob Ens</i> складається з усіх можливих множин, клас <i>Mor Ens</i>&nbsp;— із всеможливих від­ображень множин одна в одну), тополог. просторів <i>Top</i> (клас <i>Ob Top</i> складається із всеможливих тополог. просторів, клас <i>Mor Top</i>&nbsp;— з усіх неперерв. від­ображень тополог. просторів), груп <i>Gr</i> (клас <i>Ob Gr</i> складається із всеможливих груп, <i>Mor Gr</i>&nbsp;— з усіх гомоморфізмів груп); множе­н­ня збігається з послідов. викона­н­ням від­ображень (у перших двох випадках) і геоморфізмів (у третьому). Пів­група з одиницею є категорією з одним обʼєктом, і, навпаки, кожна категорія з одним обʼєктом є пів­групою з одиницею. У наведених прикладах усі категорії конкретні, тобто ізоморфно вкладаються в категорію множин. Але не всі категорії є конкретними. Запас прикладів категорій можна значно роз­ширити за допомогою різноманіт. кон­струкцій, зокрема категорії функторів або категорії діа­грам. У 1950-х рр. теоретико-категор. аналіз основ теорії гомологій зумовив появу т. зв. абелевих категорій, у рамках яких стало можливим зробити осн. побудови гомолог. алгебри. У на­ступ. десятиліт­ті значно зріс інтерес до неабелевих категорій, які сприяли роз­вʼязан­ню нових задач логіки, заг. алгебри, топології та алгебраїч. геометрії. Інтенсив. роз­виток універсал. алгебри й аксіоматичні побудови теорії гомотопій заклали основи категор. ви­вче­н­ня многовидів універсал. алгебр, теорії ізоморфізмів прямих роз­кладів, теорії спряжених функторів, теорії дво­їстості функторів. Остан. часом виявлено сут­тєві взаємозвʼязки між цими дослідже­н­нями. Завдяки теорії від­нос. категорій встановлено дво­їстість між теорією гомотопій і теорією універсал. алгебр, що базується на інтер­претації категор. ви­значень моноїда і комоноїда в певних категоріях функторів. Водночас із роз­витком заг. теорії від­нос. категорій математики за­ймаються виділе­н­ням спец. конкрет. класів таких категорій.</p>

</div>

<script>

document.addEventListener("DOMContentLoaded", function () {
    // Елементи
    const navbar      = document.querySelector(".navbar");
    const secondLevel = document.querySelector(".second");
    const h1Element   = document.querySelector("h1");
    const progressBar = document.querySelector(".scrollindicator");

    if (!navbar || !secondLevel || !h1Element || !progressBar) {
        console.warn("Scroll header or progress bar elements not found");
        return;
    }

    // Створюємо фіксований хедер
    const fixedHeader = document.createElement("div");
    fixedHeader.id = "fixed-header";
    fixedHeader.innerHTML = `
        <div class="block">
            <span class="title">${h1Element.textContent}</span>
            <a href="/"><img src="/img/svg/logo.svg" alt="Енциклопедія Сучасної України"></a>
        </div>
    `;
    document.body.appendChild(fixedHeader);

    let scrollTimeout;
    let isHeaderVisible = false;

    function handleScroll() {
        clearTimeout(scrollTimeout);

        scrollTimeout = setTimeout(() => {
            const h1Rect = h1Element.getBoundingClientRect();
            const isH1InView = h1Rect.top < window.innerHeight && h1Rect.bottom > 0;

            const shouldShow = !isH1InView;

            // Синхронно керуємо хедером і прогрес-баром
            if (shouldShow && !isHeaderVisible) {
                navbar.classList.add("hidden");
                secondLevel.classList.add("hidden");
                fixedHeader.classList.add("show");
                progressBar.classList.add("visible");
                isHeaderVisible = true;
            } 
            else if (!shouldShow && isHeaderVisible) {
                navbar.classList.remove("hidden");
                secondLevel.classList.remove("hidden");
                fixedHeader.classList.remove("show");
                progressBar.classList.remove("visible");
                isHeaderVisible = false;
            }

            // Оновлюємо прогрес незалежно від видимості
            const scrollTop = document.documentElement.scrollTop || document.body.scrollTop;
            const scrollHeight = document.documentElement.scrollHeight - document.documentElement.clientHeight;
            const progress = scrollHeight > 0 ? (scrollTop / scrollHeight) * 100 : 0;

            progressBar.value = progress;
            progressBar.setAttribute('aria-valuenow', Math.round(progress));

        }, 10); // невелика затримка для плавності
    }

    // Основний слухач скролу з throttling
    let ticking = false;
    window.addEventListener('scroll', () => {
        if (!ticking) {
            requestAnimationFrame(() => {
                handleScroll();
                ticking = false;
            });
            ticking = true;
        }
    }, { passive: true });

    // Початкове оновлення (на випадок, якщо сторінка вже прокручена)
    setTimeout(handleScroll, 100);
});
</script>
