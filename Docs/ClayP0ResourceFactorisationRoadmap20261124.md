## Exact endpoint and quantifier repair
For every finite deterministic machine D, integers c,k >=1, if D halts on every input of length n within c(n+1)^k, there exists a canonical encoded formula phi on which D's Boolean answer differs from SAT(phi). Equivalently no single uniform polynomial-time SAT decider exists. Quantify over a fixed machine BEFORE choosing the counterexample; per-length minimization over arbitrary machines is not equivalent, since finite truth tables can be hard-coded. A superpolynomial unrestricted circuit lower bound for an explicit NP language is a stronger sufficient alternative. A fixed polynomial lower bound is not enough.

## L1/L2: payable exact mathematical lemmas
R1 complete separator factorisation: if every input-to-output path crosses cut S, then output is a function of S values (include bypass inputs and constants); prove by topological evaluation. For split x,q, require h(x) independent of q, or use a full interactive transcript with a separately proved rectangle property.
R2 indexed residual injection: if F(x,q)=g(h(x),q) for all x,q then choose one representative of each distinct row F(x,-); their h values are injective. For b Boolean wires, K <= 2^b. Joint rows over lines are intersection of equivalence relations, not sum of log counts. Identity observer and output observer are negative controls. This is an elementary derived theorem, not new complexity separation.
R3 overlap chain: for finite random X and row variables R_i, H(R_1,...,R_m)=sum_i H(R_i|R_<i) <= H(h(X)) <= b under R2. Independent distinctions may add; duplicates do not. No independent private charging by default.
R4 complete trace accounting: finite DAG each node paid once, fanout free only in chosen model, inputs/edges/read events explicitly scoped. For machine, time counts primitive transitions; bit-cost and memory liveness separate. For trace cuts S_j and nonnegative weights a_j satisfying sum_{j:v in S_j} a_j <= 1 for every paid vertex v, sum_j a_j |S_j| <= number of paid vertices. If input/bypass wires are free, subtract them or establish a paid-only bound; do not charge them as gates. This is double counting, not a proof that sufficiently many expensive cuts exist.
R5 liveness negative control: recomputation may reduce peak storage while increasing work; sharing may reduce work while increasing liveness. Fast pi provides exact equal-output optimization fixture. Include arithmetic operand widths, quotient/remainder, allocation lifetimes, and source identity; no unit-cost unbounded integers. A single residual cut has at most 2^n classes for n-bit input and cannot give superpolynomial total work by itself.

## L3: genuinely open universal cut/payment lemmas
U1 standard-machine coverage: for arbitrary fixed D with polynomial clock, construct the full costed factorisation trace (including input rereads, control, addresses, memory, recomputation) preserving acceptance and polynomial overhead with constants independent of input length. Circuit alternative: arbitrary bounded fan-in Boolean DAG, negation, shared gates, unrestricted topology. No restricted-family coverage promoted.
U2 consumer attachment: on original SAT input family or a polynomial-size reduction from an explicit NP language, prove an unavoidable residual/query decomposition for every covered computation; show query independence or account for interaction and bypass. Mere syntactic cut choice is insufficient.
U3 overlap-aware packing: construct weighted unavoidable cuts/obligations and prove bounded charge per paid primitive for *every* admissible computation, not assume it. RC2 private gate conjecture is a concrete restricted-model proving ground; use actual upstream arc promise, OR/AND cross gates and line geometry, including quadratic decoder counterexample. Establish original function and model before claiming inequality.
U4 global lower bound: combine R2/R3 with U2/U3 to produce lower bound L(n) on actual total bit/transition cost, with all constants and input lengths tracked. Need new mathematical invariant; cannot use output entropy or simply count assignments. Full state/output factorisation is trivial and insufficient.

## L4: genuinely open asymptotic payment
A1 explicit hard family: define NP language, uniform generation of instance family where needed, encoding lengths and SAT reductions; prove residual growth in the cost model rather than on succinct unexpanded input. 
A2 superpolynomial amplification: for every k,c and covered D, exhibit length/input on which cost exceeds c(n+1)^k or correctness fails. If proving uniform bound L(n), show L(n)/(n+1)^k unbounded for every fixed k. A finite q^3 / n^(3/2) lower bound, exponential number of witnesses, or exponential residual profiles alone does not suffice. Prove composition does not admit shared compression, alternate algorithms or promise-domain escape. Check relativization/natural-proofs/algebrization applicability rather than claim barrier evasion.
A3 terminal transport: deliver unconditional SATLowerBoundProducer / UniversalPolynomialSATDecisionFailure on the original formula encoding; invoke SAT NP-completeness and P subset NP. Existing terminal logical wiring is not the open inequality.
