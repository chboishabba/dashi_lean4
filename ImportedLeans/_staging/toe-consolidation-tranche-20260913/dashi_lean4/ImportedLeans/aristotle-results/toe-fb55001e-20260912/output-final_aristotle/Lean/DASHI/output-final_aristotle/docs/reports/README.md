# Diagnostic reports

Generated by `scripts/make-reports.sh`, which runs `wikidata report` over the downloaded fragments in [`data/`](../../data). Every issue carries the identifiers it is about, the error type, whether it is an error or a style warning, and the status of the fix suggested for it — `proven-fix` when a theorem says the fix changes no derived fact, `suggested-fix` when the repair is mechanical, `needs-review` when it is destructive or ambiguous.

Each report comes in three forms: `NAME.csv` (one line per issue, for a spreadsheet), `NAME.html` (a page with a summary by error type) and `NAME.svg` (a bar chart of the counts).

Two of the reports below are of the hand-written example files in [`examples/`](../../examples): `defects` and `taxa-defects` are small bases built to carry one of each kind of problem, so every error type the tool can report appears somewhere in these tables.

The same issues grouped into things to work on — by error type, by file, by layer and by kind of work, with one CSV per task — are in [`worklist/`](worklist/README.md), written by `wikidata worklist`.
