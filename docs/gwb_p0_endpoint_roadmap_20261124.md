shifted focus/antecedent Unicode span, different parser run,
forged policy/derivation, rival PERSON, incompatible morphology,
quotation-scope change, changed S29 status, changed supporting
original evidence, false QID/truth/admission and a stale replay

plural/generic or expletive pronoun, missing source-local
uniqueness, 64-cap hidden live candidates, surname-only
co-presence and mismatched authority must never become an admitted
identity projection. Negative tests must check the production
SQL constraints and reversible retraction, not just flags.

**Independent world:** cross-work Q207 attachment, stale Q23505
revision, missing property statement or mismatched JMD source
must fail. A proof of the source **claim** is not a proof that its
historical assertion is true.
